# Coffee Delivery

Aplicação web de delivery de cafés desenvolvida em **C#**, **.NET** e **Blazor** para fins de estudo.

O objetivo do projeto é praticar conceitos de desenvolvimento web com C#, criando uma interface inspirada em um fluxo real de compra: listagem de cafés, carrinho, checkout e confirmação de pedido.

## Tecnologias

- C#
- .NET
- Blazor
- HTML
- CSS

## Funcionalidades planejadas

- Listagem de cafés disponíveis
- Adição e remoção de itens no carrinho
- Controle de quantidade dos produtos
- Cálculo do total do pedido
- Formulário de endereço
- Seleção da forma de pagamento
- Tela de confirmação do pedido

## Como executar o projeto

Clone o repositório:

```bash
git clone https://github.com/altemily/coffee-delivery.git
```

Acesse a pasta do projeto:

```bash
cd coffee-delivery
```

Rode a aplicação:

```bash
dotnet run
```

Depois, acesse no navegador o endereço exibido no terminal.

Exemplo:

```txt
http://localhost:5128
```
